#### Spring
```Java
@Component
public class MyHandler extends TextWebSocketHandler {

  @Override
  public void afterConnectionEstablished(WebSocketSession session) {
    if (session.isOpen()) 
      session.sendMessage(new TextMessage("Hi client"));
  }

  @Override
  protected void handleTextMessage(
        WebSocketSession session, TextMessage message) throws Exception {
    // Handle incoming text message
  }

  @Override
  public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
    // cleanup
  }
}
```

#### Config

```Java
@Configuration
@EnableWebSocket
@RequiredArgsConstructor
public class WebSocketConfig implements WebSocketConfigurer {

  private final MyHandler myHandler;

  @Override
  public void registerWebSocketHandlers(
        WebSocketHandlerRegistry registry) {
        
    registry.addHandler(myHandler, "/websockets")
        .setAllowedOrigins("http://localhost:4200");
  }
}
```

#### Typescript

```typescript
socket = new WebSocket('ws://localhost:8080/websockets');

constructor() {
  this.socket.onmessage = event => this.message.set(event.data);
}

send() {
  if (this.socket.readyState !== WebSocket.OPEN) 
    return;

  this.socket.send("Hi server");
}

ngOnDestroy() {
  this.socket.close();
}
```
