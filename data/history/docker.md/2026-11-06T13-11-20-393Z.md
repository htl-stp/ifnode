#### Docker CLI [run]

```
docker run [OPTIONS] image [COMMAND] [ARG...]
```
<!-- .element: class="fragment fade-in" -->

```shell
-d     # Container-stdout ignorieren
-it    # Container mit interaktivem stdin
-p     # Port zum Host öffnen
--name # Containername setzen
-rm    # Container wird nach Stop removed
-e     # Environmentvariable setzen
-v     # Volume/Bind Mount hinzufügen 
```
<!-- .element: class="fragment fade-in" -->

```shell
docker run 
-rm -d
--name container_name 
-p host_port:container_port 
image_name 
```
<!-- .element: class="fragment fade-in" -->

#### Dockerfile

```dockerfile
FROM python-base:v1

RUN pip install pyfiglet
WORKDIR /app
COPY app2/. .
CMD python /app/greet.py
```
<!-- .element: class="fragment fade-in" -->

<dl>
    <div class="fragment fade-in-then-semi-out">
    <dt>FROM base-image</dt>
    <dd>Basisimage, das erweitert wird</dd>
    </div>
    <div class="fragment fade-in">
    <dt>RUN command</dt>
    <dd>Command wird während des Imagebuilds ausgeführt</dd>
    </div>
    <dd class="fragment fade-in">Packages installieren, User anlegen, ...</dd>
    <dd class="fragment fade-in">Fügt einen Layer zum Image hinzu</dd>

</dl>

---

<dl>
<div class="fragment fade-in-then-semi-out">
    <dt>WORKDIR path</dt>
    <dd>Erzeugt path und setzt ihn als Working Directory</dd>
</div>
<div class="fragment fade-in-then-semi-out">
    <dt>COPY host-path image-path</dt>
    <dd>Kopiert Files vom Host in das Image</dd>
</div>
<div class="fragment fade-in-then-semi-out">
    <dt>USER user/uid</dt>
    <dd>Linux-(VM)-User, welcher die Commands ausführt</dd>
</div>
<div class="fragment fade-in-then-semi-out">
    <dt>ENV name value</dt>
    <dd>Setzt Environment Variablen</dd>
</div>
<div class="fragment fade-in">
    <dt>EXPOSE port</dt>
    <dd>Das Image <em>empfiehlt</em> einen Port zu öffnen</dd>
</div>
</dl>

#### CMD
```
FROM ubuntu
CMD ["/bin/echo", "Hello World"]
```
<!-- .element: class="fragment fade-in" -->

```shell
docker run image => Hello World
docker run image ls => 
docker run image something => 💥 No such command
```
<!-- .element: class="fragment fade-in" -->

* Command wird ausgeführt, wenn der Container startet
<!-- .element: class="fragment fade-in-then-semi-out" -->
* Kann überschrieben werden
<!-- .element: class="fragment fade-in" -->

#### ENTRYPOINT

#### Networking

Frontend-Container will mit Backend-Container kommunizieren
<!-- .element: class="fragment fade-in" -->

💡 beides zusammen in ein Dockerfile
<!-- .element: class="fragment fade-in-then-semi-out" -->

SRP 🫣
<!-- .element: class="fragment fade-in-then-semi-out" -->

```typescript
// docker inspect Backend -> IP des Containers
url = 'http://172.17.0.42:8080'
```
<!-- .element: class="fragment fade-in-then-semi-out" -->

Neustart ⟹ neue IP 🤮
<!-- .element: class="fragment fade-in-then-semi-out" -->

```typescript
// port am Backend freigeben: -p 8080:8080
url = 'http://host.docker.internal:8080'
```
<!-- .element: class="fragment fade-in-then-semi-out" -->

Security 🫣
<!-- .element: class="fragment fade-in-then-semi-out" -->

---

```shell
docker network create my_network
docker network connect my_network backend_container
docker run 
    --network my_network 
    --name frontend_container 
    --port 80:4200
    frontend
url = 'http://backend_container:8080'
```
<!-- .element: class="fragment fade-in" -->
<!-- .element: class="fragment fade-in" -->
Keine Portfreigabe innerhalb des Netzwerks *notwendig*
<!-- .element: class="fragment fade-in" -->
